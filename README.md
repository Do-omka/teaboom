# Верхняя часть карточки товара

[Ананасовый улун](https://teaboom.ru/product/ananasovij-ulun).

Я бы сохранил наглядное отображение всех параметров вариантов фасовки. Удобнее сразу видеть цены, а переключать толком нечего.
Сложно представить сохранение текущего стиля сайта, постарался подобрать чайные цвета и сделал минимальные округления.

## Установка

```bash
nvm use
npm install
```

## Локальная разработка

```bash
npm run dev
```

## Сборка

```bash
npm run build
```
